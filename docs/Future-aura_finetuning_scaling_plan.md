# AURA — Domain-Specialized Fine-Tuning + 1000+ User Serving Plan (BD Cost Estimate)

*দাম যাচাই করা হয়েছে: GPU rental rates ও USD-BDT rate (আজকের হিসেবে ১ USD ≈ ১২৩ টাকা) সেপ্টেম্বর ২০২৬-এর হিসেবে। এগুলো ওঠানামা করে — বাস্তব বাজেট করার আগে আবার যাচাই করে নেবেন।*

## কৌশলটা কী, এবং কেন এটা বাস্তবসম্মত

"সব বিষয়ে ChatGPT-কে হারানো" বাস্তবসম্মত না। কিন্তু **নির্দিষ্ট একটা subject/domain-এ** (ধরুন: বাংলাদেশি আইন, নির্দিষ্ট মেডিকেল স্পেশালিটি, স্থানীয় কৃষি, বাংলা ভাষার কনটেন্ট) fine-tuning + curated data দিয়ে একটা general-purpose মডেলকে (ChatGPT সহ) ছাড়িয়ে যাওয়া **প্রমাণিত ও অর্জনযোগ্য** — এটাই আসলে ছোট টিমের জন্য realistic জয়ের জায়গা। তিনটা উপাদান লাগবে:

1. **ভালো base model** (Llama 3.1 70B, Qwen2.5-72B, বা DeepSeek-R1-Distill-70B)
2. **উচ্চমানের domain-specific training data** — এটাই আসল যুদ্ধক্ষেত্র, GPU না
3. **Fine-tuning (QLoRA) + DPO alignment** + RAG দিয়ে সাজানো

## ১. Base Model বাছাই

| মডেল | কেন |
|---|---|
| **Qwen2.5-72B-Instruct** | ভালো multilingual (বাংলাসহ), fine-tune করা তুলনামূলক সহজ, Apache license |
| **Llama 3.1 70B-Instruct** | বড় community, ভালো tooling সাপোর্ট |
| **DeepSeek-R1-Distill-Llama-70B** | reasoning-heavy কাজে (গণিত, যুক্তি) ভালো, DeepSeek-এর reasoning distill করা |

**পরামর্শ:** Qwen2.5-72B দিয়ে শুরু করুন — বাংলা ভাষায় স্বাভাবিকভাবেই ভালো পারফর্ম করে, যেটা DeepSeek/Llama-তে কম।

## ২. Fine-Tuning-এর জন্য যা লাগবে (এককালীন/পর্যায়ক্রমিক খরচ)

### হার্ডওয়্যার
- **QLoRA fine-tuning** (পুরো model retrain না, efficient adapter-tuning) দিয়ে 70B মডেল ট্রেন করতে বাস্তবসম্মতভাবে লাগবে: **৪x NVIDIA H100 80GB** (বা ৪x A100 80GB, একটু ধীর কিন্তু সস্তা)
- RAM: প্রতি GPU node-এ কমপক্ষে ২৫৬GB system RAM
- Storage: ২-৫TB fast NVMe SSD (dataset + checkpoints)

### ভাড়া নেওয়ার খরচ (নিজে কেনার দরকার নেই)
| GPU | দাম/ঘণ্টা (USD) | দাম/ঘণ্টা (BDT, ১$=১২৩৳) |
|---|---|---|
| A100 80GB | $1.50–2.50 | ৳১৮৫–৩০৮ |
| H100 80GB | $2.50–3.50 | ৳৩০৮–৪৩০ |

একটা সম্পূর্ণ fine-tuning cycle (dataset প্রস্তুতি বাদে, শুধু training run): ৪x H100 দিয়ে ৫০-১৫০ ঘণ্টা (dataset সাইজের উপর নির্ভর করে) →
**খরচ: $500–2,100 (≈ ৳৬২,০০০–২,৬০,০০০) প্রতি cycle**

*(এটা periodic — প্রতি ১-৩ মাসে নতুন ডেটা দিয়ে re-fine-tune করা লাগতে পারে)*

### ডেটা তৈরি — এটাই সবচেয়ে গুরুত্বপূর্ণ, সবচেয়ে কম আলোচিত অংশ
নির্দিষ্ট subject-এ ভালো হতে হলে দরকার:
- কমপক্ষে ৫,০০০-৫০,০০০ উচ্চমানের, ভেরিফায়েড প্রশ্ন-উত্তর জোড়া (expert-reviewed)
- Domain expert(দের) দিয়ে answer quality যাচাই (subject matter expert লাগবে, প্রতি বিষয়ে আলাদা)
- DPO-এর জন্য "ভালো উত্তর vs খারাপ উত্তর" জোড়া তৈরি (comparison data)

## ৩. ১০০০+ ইউজার সার্ভ করতে যা লাগবে (চলমান/মাসিক খরচ)

**গুরুত্বপূর্ণ পার্থক্য:** ১০০০ **রেজিস্টার্ড** ইউজার (যাদের মধ্যে হয়তো ৫-১০% একসাথে সক্রিয় থাকে) আর ১০০০ **একসাথে সক্রিয়** (concurrent) ইউজার — সম্পূর্ণ ভিন্ন হিসাব। নিচে দুটোই দিলাম।

## ৬. সততার সাথে ঝুঁকি ও বাস্তবতা

- **ডেটা-ই আসল যুদ্ধ, GPU না।** সবচেয়ে বেশি বাজেট আর সময় data curation ও domain expert review-তে যাওয়া উচিত — এটাই ChatGPT-এর চেয়ে ভালো হওয়ার আসল কারণ হবে, বড় GPU cluster না।
- **প্রথমেই ১০০০+ concurrent-এর জন্য GPU কিনে/ভাড়া করে ফেলবেন না** — auto-scaling সহ ছোট শুরু করুন, ব্যবহার বাড়ার সাথে সাথে scale করুন।
- **"ছাড়িয়ে যাওয়া" প্রমাণ করতে** ব্লাইন্ড A/B টেস্ট দরকার হবে (একই প্রশ্ন ChatGPT আর আপনার মডেলকে দিয়ে, subject expert-দের দিয়ে blind ভোট করানো) — এটা QA বাজেটেই ধরা আছে।
- GPU দাম ও exchange rate ওঠানামা করে — চূড়ান্ত সিদ্ধান্তের আগে আবার যাচাই করুন।
